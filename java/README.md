## Como rodar

**Exercício solto (um `.java`):**
```bash
javac Main.java && java Main
```

**Projeto Spring Boot (Maven):**
```bash
./mvnw spring-boot:run           # Windows: mvnw.cmd spring-boot:run
```

> Cada projeto Spring Boot fica numa pasta própria com seu `pom.xml`. Não commitar `target/` nem arquivos da IDE (já está no `.gitignore`).
