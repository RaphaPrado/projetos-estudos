## 📐 Convenções

**Nomes de pasta:** `kebab-case`, com prefixo numérico quando a ordem importa.
```
01-variaveis-e-tipos/
02-estruturas-condicionais/
```

**Mensagens de commit** (Conventional Commits):
```
feat(java): lista encadeada com inserção e remoção
feat(dados): exercício de groupby com pandas
fix(web): corrige layout flexbox do landing page
docs: atualiza progresso no README
```

**Cada exercício/projeto** tem (quando fizer sentido) um `README.md` curto:
o que é, o que aprendi, como rodar.
